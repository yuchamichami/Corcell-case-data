# Corcell Case Data

Corcellのケースデータを3MF形式で配布しています。

## ダウンロード・バージョン

| バージョン | 対応する販売分 | データ |
| --- | --- | --- |
| V1 | 8月22日注文分 | [V1フォルダ](V1/) |
| V2 | キーフリ2026以降の販売分 | [V2フォルダ](V2/) |

**基板形状は同一のため、どちらの販売分でもV1・V2両方のケースを使用できます。**

一括ダウンロードは[ZIPをダウンロード](https://github.com/yuchamichami/Corcell-case-data/archive/refs/heads/main.zip)から行えます。

| ケース色 | フィラメント |
| --- | --- |
| ブラック | Bambu PLAマット — マットチャコール |
| ホワイト | **Bambu PLAマット — マットアイボリーホワイト** |

## 組み立て

### トラックボールの固定

トラックボールの固定には、**M1.7・長さ8 mmのネジ**を使用します。

### 乾電池の蓋

ボトムケース底面とビルドプレートの模様を合わせるため、蓋本体と蓋の底面パーツを別々に印刷し、**瞬間接着剤で貼り合わせます。**

## 販売品のフレームの仕上げ

販売品のフレームは、以下の手順で仕上げています。

1. 少しヒケが出る程度にアイロン処理を行います。
2. **400番程度のやすり**で、アイロンをかけた面と面取り面をなめらかに整えます。
